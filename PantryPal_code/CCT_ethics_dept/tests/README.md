This folder contains the Clause → Control → Test (CCT) verification suite for PantryPal.
Each test corresponds directly to one of the 10 PIPEDA privacy principles, ensuring your backend, cloud infrastructure, and data governance are compliant with the commitments stated in your Telemetry Matrix and Ethics Ledger.

These tests are fully local, written in JavaScript, and do not require AWS credentials.

# Running the CCT Test Suite

```
./run_all_tests.sh
```
